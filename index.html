For Beginners

📌 What is Git?

Git is a Version Control System that tracks changes in your code.

Think of it as a time machine for your project.

git init git add index.html git commit -m "first commit"

🌐 What is GitHub?

GitHub is a cloud platform where you store Git projects online.

Think of it like Google Drive for developers.

⚔️ Git vs GitHub

  • Git: Software (tracks code)
  • GitHub: Cloud platform (stores code)
  • Git: Works offline
  • GitHub: Needs internet

📤 Upload Project Steps

  • Create GitHub Repository
  • git init
  • git add .
  • git commit -m "first commit"
  • git push origin main

🔥 Most Used Git Commands

  • git status
  • git log
  • git branch
